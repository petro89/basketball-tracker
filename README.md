# Basketball Tracker

Личный баскетбольный трекер: счётчик бросков, ручная карта попаданий, история тренировок, измерение прыжка и анализ техники.

## Android APK

[Скачать актуальный тестовый APK](https://github.com/petro89/basketball-tracker/releases/download/android-apk-latest/app-debug.apk)

GitHub Actions собирает APK при каждом обновлении ветки `main` и прикладывает его к тестовому релизу.

### Установка

1. Открой ссылку APK на Android-телефоне и скачай файл.
2. Открой APK и подтверди установку. Android может попросить разрешить установку приложений из используемого браузера или файлового менеджера.
3. При первом запуске разреши доступ к камере, если хочешь пользоваться камерой и видеоанализом.

### Важные ограничения первой версии

- Это WebView-приложение: оно открывает трекер внутри отдельного окна приложения, поэтому не нужно каждый раз искать сайт в браузере.
- Интернет пока обязателен: сам трекер и библиотеки ИИ загружаются с сайта и CDN.
- Данные, сохранённые в браузере, автоматически не переносятся в приложение: Android-приложение использует собственное хранилище. Сохранённые внутри приложения тренировки остаются в нём при обычном запуске.
- Текущий APK — тестовая сборка с отладочной подписью, не релиз для Google Play. Перед массовым распространением настроим стабильную подпись APK и полноценный выпуск.
- Для карты бросков нажми «Сохранить тренировку в историю». Вкладка «История» позволяет открыть карту сохранённой тренировки и статистику каждой отмеченной точки.

## Сборка

Проект использует Android Gradle Plugin и собирается GitHub Actions. APK также доступен как workflow artifact в запуске сборки.
